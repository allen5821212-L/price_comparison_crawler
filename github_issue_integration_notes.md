# GitHub Issue Integration Notes

- Issue tracker repository: `https://github.com/allen5821212-L/price-comparison-crawler-issues`.
- The repository is private and has GitHub Issues enabled.
- The authorized project GitHub account has administrative and write access through the GitHub API.
- An unauthenticated browser is redirected to GitHub sign-in before it can open a private Issue draft. The application therefore routes Issue-draft actions through GitHub login and retains Markdown-copy reporting as the access fallback.
